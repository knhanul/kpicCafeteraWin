# 6단계 문서 출력 시스템 — 수동 검증 체크리스트

> 자동 검증(테스트)으로 확인할 수 없는 항목: 한컴오피스 COM 자동화 PDF 변환, WPF PDF 미리보기.
> 한컴오피스가 설치된 PC에서 아래 항목을 순서대로 확인한다.

## 준비물

- 한컴오피스(한글) 설치 PC
- 검증용 생성 문서: `artifacts/verification/` 아래 3종 HWPX
  - `식단표_6주.hwpx` (3페이지)
  - `조리지시서_10일.hwpx` (10페이지)
  - `보존식기록지_10식.hwpx` (4페이지)
