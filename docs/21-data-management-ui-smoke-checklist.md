# 데이터 관리 UI 수동 검증 체크리스트

## 사전 조건

- `KpicCafeteria.Desktop` 빌드 및 실행
- `데이터 관리` 메뉴 선택

## 이관 (Import)

- [ ] `파일 선택` 클릭 후 `*.xlsx` 파일 선택
- [ ] `Preview` 클릭 시 각 시트별 행 수, 오류/경고 메시지 출력
- [ ] Preview 완료 후 `Replace` / `Merge` 버튼 활성화
- [ ] `Merge` 적용 시 기존 데이터를 보존하며 데이터 추가
- [ ] `Replace` 적용 시 확인 대화상자 → 자동 사전 백업 → 데이터 교체
- [ ] 이관 완료 후 오류/성공 상태 메시지 확인

## 백업 / 복구

- [ ] 화면 진입 시 백업 목록 자동 로드
- [ ] `지금 백업` 클릭 시 `*.kpicbackup` 파일 생성
- [ ] 백업 목록에 파일명/유형/상태/생성일 표시
- [ ] 복원할 백업 선택 후 `복구` 클릭
- [ ] 복구 확인 대화상자 → 사전 백업 → 복구 → 앱 재시작
- [ ] 복구 후 기존 데이터가 백업 시점으로 복원됨

## Excel 아카이브

- [ ] 시작일/종료일 선택
- [ ] `아카이브 생성` 클릭 시 저장 위치 선택
- [ ] 저장된 `데이터아카이브_YYYYMMDD-YYYYMMDD.xlsx` 파일 열기
- [ ] 아카이브에 `식단재료`, `발주기록`, `발주그룹` 시트 포함 확인

## 예외 상황

- [ ] 잘못된 XLSX 선택 시 사용자 친화적 오류 메시지
- [ ] 백업 파일이 없을 때 복구 버튼 비활성화
- [ ] 시작일 > 종료일 시 아카이브 생성 금지
