# 17. Orders(발주 관리) UI 수동 검증 체크리스트

> 작성일: 2026-08-16
> 자동 테스트는 업무규칙을 검증했지만, 실제 WPF 화면 조작은 자동화할 수 없어
> 사용자가 직접 확인해야 하는 항목을 정리한다.

## 1. 실행 방법

```powershell
cd C:\Pjt\kpicCafeteriaWin
dotnet run --project .\src\KpicCafeteria.Desktop\KpicCafeteria.Desktop.csproj
```

## 2. 사전 준비 (Workspace에서 식단 작성)

- [ ] 주간 급식 운영 → 배식 생성 → 메뉴 일괄 추가 (재료 포함)
- [ ] 같은 재료를 다른 메뉴에 사용 (양파 10kg + 5kg 등)

## 3. 발주 화면 기본 동작

- [ ] 좌측 네비게이션 → 발주 관리 클릭
- [ ] 기본 조회 기간 2주 표시, From/To 자동 설정
- [ ] 필요량이 식단과 일치 (같은 날짜 같은 재료 합산)
- [ ] 재료별 보기: 재료명 → 사용일 정렬
- [ ] 사용일별 보기: 사용일 → 재료명 정렬
- [ ] 정렬 변경(발주일/배송일/상태) 동작

## 4. 판매 포장단위 설정

- [ ] 식재료 화면 → 재료 선택 → 판매 포장수량/판매 포장단위 입력 → 저장
- [ ] 예: 데미글라스소스 기본단위 g, 판매 2kg
- [ ] 발주 화면 재조회 → 추천량 열에 "2kg" 표시
- [ ] 800g 필요 / 2kg 판매단위 → 추천 2kg 확인
- [ ] 4.1kg 필요 / 2kg 판매단위 → 추천 6kg 확인
- [ ] 포장단위 없는 재료 → 추천량 = 필요량
- [ ] 호환 불가 단위(개+판 등) → "포장단위 확인 필요" 표시

## 5. 실제 발주량 수정

- [ ] 실제 발주량 직접 수정 (예: 추천 2kg → 3kg)
- [ ] 발주일/배송일 변경
- [ ] 상태 변경: 미처리 → 발주완료 / 발주안함
- [ ] 비고 입력 (예: "납품시간 확인")
- [ ] 변경사항 저장 클릭 → "저장되었습니다."
- [ ] 재조회 후 입력값 유지

## 6. 사용자 입력 보존

- [ ] Workspace에서 식단 수량 변경 (예: 양파 5kg → 8kg)
- [ ] 발주 화면 재조회 → 필요량만 최신화, 실제 발주량/상태 유지
- [ ] 식단에서 재료 제거 → 발주 화면에 "식단에서 제외됨" 표시, 기존 입력 유지

## 7. 묶음 발주

- [ ] 같은 재료 여러 사용일 항목 체크 → 묶음 발주 클릭
- [ ] 대화상자에 필요량 합계/추천량 표시
- [ ] 발주량/발주일/배송일 확정 → 묶음 발주 클릭
- [ ] 항목 상태가 발주완료로 변경, 발주일/배송일 동기화
- [ ] 서로 다른 재료 선택 시 오류 메시지

## 8. 일괄 변경

- [ ] 여러 항목 체크 → 일괄 변경 클릭
- [ ] 발주일/배송일/상태 중 일부만 입력 → 적용
- [ ] 입력 안 한 항목은 변경되지 않음
- [ ] 아무것도 입력하지 않으면 "변경할 항목이 없습니다." 메시지

## 9. Dirty 확인

- [ ] 발주량 수정 후 저장 없이 다른 화면 이동 → 확인 대화상자
- [ ] 조회 클릭 시 변경 사라짐 경고

## 10. 재실행

- [ ] 앱 종료 후 재실행 → 발주 화면에서 실제 발주정보 유지 확인

## 11. 알려진 미확인 사항

- **묶음 발주 대화상자**: 추천량은 선택 항목의 첫 행 판매 포장단위 기준. 항목 간 포장단위가 다르면 직접 수정 필요
- **DataGrid 편집**: 셀 편집 후 다른 행 이동 시 값 유지 여부 확인 필요
- **200건 초과**: 기간을 좁혀 조회하는 구조 (전체 스크롤 미지원, 의도)
