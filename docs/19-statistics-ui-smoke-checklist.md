# 19. Statistics(통계·운영 대시보드) UI 수동 검증 체크리스트

> 작성일: 2026-08-16
> 자동 테스트는 계산 로직을 검증했지만, 실제 WPF 화면 조작은 자동화할 수 없어
> 사용자가 직접 확인해야 하는 항목을 정리한다.

## 1. 실행 방법

```powershell
cd C:\Pjt\kpicCafeteriaWin
dotnet run --project .\src\KpicCafeteria.Desktop\KpicCafeteria.Desktop.csproj
```

## 2. 사전 준비 (데이터)

- [ ] 주간 급식 운영에서 2주 이상 식단 작성 (메뉴·재료 포함, 실제 식수 입력 포함)
- [ ] 보존식 완료/수거/폐기 기록, 식단표·조리지시서 출력 기록 포함
- [ ] 같은 메뉴를 2주 내 2회 이상 사용 (반복 메뉴 확인용)
- [ ] 일부 배식은 실제 식수 미입력 (누락/입력률 확인용)

## 3. 네비게이션

- [ ] 좌측 네비게이션 "통계" 그룹에 5개 버튼 표시
- [ ] 운영 대시보드 / 식수 통계 / 메뉴 통계 / 식재료 통계 / 운영 기록 통계 각각 클릭 → 화면 전환
- [ ] 발주 화면에서 저장하지 않은 변경 후 통계 이동 → 확인 대화상자
- [ ] 통계 화면에서 다른 화면 이동 시 오류 없음

## 4. 공용 필터 바 (모든 통계 화면)

- [ ] 기간 프리셋: 이번 달/최근 3개월/6개월/12개월/올해/직접 선택
- [ ] 프리셋 변경 시 데이터 즉시 갱신 (로딩 표시 후)
- [ ] 직접 선택 시 시작일/종료일 DatePicker 활성화, 변경 시 즉시 갱신
- [ ] 식사유형: 전체/중식/석식 변경 시 데이터 갱신
- [ ] 상태 텍스트에 조회 기간 표시 (예: 2026-01-01 ~ 2026-01-31)

## 5. 운영 대시보드

- [ ] KPI 카드: 운영일수/고유 메뉴 수/중식/석식 값 표시
- [ ] 월별 식수 추세(계획/실제) 막대 표시, 값 텍스트 표시
- [ ] 메뉴 사용 현황 상위 5 / 반복 메뉴 / 재료군 사용량(kg) 표시
- [ ] 업무 기록 현황: 조리지시서/보존식/실제식수 건수 표시
- [ ] 식수 이상/메뉴 반복/재료 사용량 변화/기록 누락 목록 표시
- [ ] 데이터 없는 기간 → 빈 목록, 오류 없음

## 6. 식수 통계

- [ ] KPI: 운영일수/총 계획/총 실제/입력률/편차/중식/석식
- [ ] 요일별 평균 (월~금) 계획/실제/입력 횟수
- [ ] 월별 추세 계획/실제 막대
- [ ] 식수 이상치: 날짜/요일/구분/유형/수준/편차율/평소 대비 편차
- [ ] 백데이터: 날짜/요일/구분/계획/실제/차이/편차율/평소 중앙값/평소 편차/입력
- [ ] 백데이터 검색: 날짜(yyyy-MM-dd)·구분·요일 필터 동작

## 7. 메뉴 통계

- [ ] KPI: 고유 메뉴 수/총 사용 횟수/신규/반복/미사용
- [ ] 상위 메뉴 목록: 메뉴명/역할/사용/중식/석식/첫 사용/최근/평균 간격
- [ ] 상위 메뉴 "보기" 클릭 → 우측 상세 패널 표시
- [ ] 상세 패널: 월별 사용/최근 이력/함께 사용된 메뉴/사용 이력
- [ ] 상세 패널 "닫기" 클릭 → 패널 숨김
- [ ] 반복 메뉴 (14일 2회/28일 3회) 표시
- [ ] 미사용 메뉴 (최근 90일) 표시
- [ ] 백데이터 검색: 날짜·메뉴명·구분 필터 동작

## 8. 식재료 통계

- [ ] KPI: 고유 식재료 수/총 사용 횟수/신규/미사용
- [ ] 상위 식재료: 식재료명/재료군/사용/사용량/중식/석식/첫 사용/최근/평균 간격
- [ ] "보기" 클릭 → 상세 패널 (월별 사용/최근 이력/함께 사용된 식재료/사용 이력)
- [ ] 미사용 식재료 (최근 90일) 표시
- [ ] 백데이터 검색: 날짜·식재료명·구분 필터 동작

## 9. 운영 기록 통계

- [ ] KPI: 배식 건수/실제 식수 입력률/보존식 완료율/식단표 출력률/조리지시서 출력률/중식/석식
- [ ] 월별 완료율 추세: 실제 입력/보존식/조리지시서 막대
- [ ] 기록 누락 목록: 날짜/요일/구분/유형
- [ ] 지연 입력 목록: 날짜/구분/계획/실제/기록 시각
- [ ] 보존식 분석: 수거/폐기 건수·비율, 담당자별, 온도 기록
- [ ] 백데이터: 실제 입력/지연/식단표/조리지시서/보존식/수거/폐기/담당자/온도
- [ ] 백데이터 검색 필터 동작

## 10. 성능

- [ ] 12개월 기간 조회 시 2~3초 내 화면 표시 (로딩 중 표시 확인)
- [ ] 기간/식사유형 빠르게 연속 변경 시 오류 없음 (IsBusy 가드)
- [ ] 백데이터 검색 입력 시 UI 멈춤 없음

## 11. 재실행

- [ ] 앱 종료 후 재실행 → 통계 화면 정상 표시, 기간 기본값 이번 달

## 12. 알려진 미확인 사항

- **차트**: 가로 막대만 지원 (툴팁/범례/축 눈금 없음, 의도)
- **백데이터**: 페이지네이션 없음 — 기간이 길면 행이 많아질 수 있음 (검색 필터로 좁힘)
- **미사용 기준**: 90일 고정 (Python 기본값과 동일)
