# 14. Master Data UI 수동 검증 체크리스트

> 작성일: 2026-08-16
> 자동 테스트는 업무규칙을 검증했지만, 실제 WPF 화면 조작은 자동화할 수 없어
> 사용자가 직접 확인해야 하는 항목을 정리한다.

## 1. 실행 방법

```powershell
cd C:\Pjt\kpicCafeteriaWin
dotnet run --project .\src\KpicCafeteria.Desktop\KpicCafeteria.Desktop.csproj
```

## 2. 식재료 화면 (좌측 네비게이션 → 식재료)

- [ ] 식재료 등록: 새 재료 → 표준 재료명/통계분석군/기본단위 입력 → 저장
- [ ] 저장 후 목록에 표시되는지
- [ ] 같은 이름 재료 중복 등록 시 "같은 이름의 재료가 있습니다." 메시지
- [ ] 별칭 추가/삭제 동작
- [ ] 미사용 처리 후 목록에서 "(미사용)" 표시 (미사용 포함 체크 시)
- [ ] 프로그램 재실행 후 데이터 유지

## 3. 메뉴·레시피 화면 (좌측 네비게이션 → 메뉴·레시피)

- [ ] 메뉴 등록: 새 메뉴 → 메뉴명/역할 입력 → 저장
- [ ] 레시피 생성: + 레시피 → 재료 추가 → 재료명 선택(ComboBox) → 100인 기준 수량 입력 → 저장
- [ ] 재료명 ComboBox에서 기존 재료 선택 시 정상 표시
- [ ] 재료명 ComboBox에 새 이름 입력 시 저장 후 자동 재료 생성 ("자동등록-분류필요")
- [ ] 편집 후 다른 행 이동 시 입력값 유지
- [ ] 저장 후 다시 조회 시 값 유지
- [ ] 같은 재료 구성 레시피 중복 등록 시 "같은 재료 구성의 레시피가 이미 있습니다." 메시지
- [ ] 기본 레시피 지정/변경 동작
- [ ] 메뉴 미사용 처리 시 레시피도 함께 미사용 처리 확인

## 4. 배식 기본값 화면 (좌측 네비게이션 → 배식 기본값)

- [ ] 중식/석식 기본 계획식수, 배식시간, 정렬 순서, 사용 여부, 설명 수정 → 저장
- [ ] 음수 인원 입력 시 오류 메시지
- [ ] 잘못된 시간("25:99") 입력 시 "배식시간 형식은 HH:MM이어야 합니다." 메시지
- [ ] "1140" 입력 시 "11:40"으로 정규화되는지

## 5. 알려진 미확인 사항

- **레시피 재료 ComboBox**: 재료명 단일 바인딩(Text)으로 리팩터링함. 선택/입력/행 이동/저장/재조회 시 값이 유지되는지 위 항목으로 확인 필요
- **목록 페이지네이션**: 현재 limit 200 고정. 200건 초과 시 검색어로 찾는 구조 (선택기 포함)
